# HỒ SƠ NĂNG LỰC / BRAND AMBASSADOR PROFILE (PDF)

Thư mục này chứa toàn bộ các ấn phẩm PDF Profile hoàn chỉnh dành cho in ấn hoặc gửi đối tác / thương hiệu:

1. **`Phat-Trinh-Brand-Ambassador-Profile.pdf`**:
   - Bản tiếng Việt (1 trang A4).
   - Nội dung, tone giọng thực chiến và 3 trụ cột đồng nhất 100% với landing page (`landing-trade.html`).
   - CTA: **LÀM MỘT LY?** kèm thông tin liên hệ và mã QR Zalo.

2. **`Phat-Trinh-Brand-Ambassador-Profile-EN.pdf`**:
   - Bản tiếng Anh (1 trang A4).
   - Dành cho các nhãn hàng quốc tế, bar & hotel tổng quản lý người nước ngoài.
   - CTA: **LET'S TALK** kèm thông tin liên hệ và mã QR Zalo.

### Cách tạo lại file PDF khi cần:
- Chạy lệnh:
  ```bash
  python make_pdf.py      # Tạo bản tiếng Việt
  python make_pdf_en.py   # Tạo bản tiếng Anh
  ```
